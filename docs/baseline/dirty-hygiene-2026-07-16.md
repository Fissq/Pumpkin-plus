# Dirty-гигиена Proto-чанков — до/после (2026-07-16)

**Машина:** Ryzen 7 7700 (8c/16t), NVMe, btrfs, CachyOS (kernel 7.1.3-2).
**Ветка:** `fix/io-path`, коммиты `6fcc5697`…`3c9de41e`.

## Задача

Чтение уже сгенерированной территории не должно порождать запись на диск.
До изменения кольцевые Proto-чанки (кайма ~5 чанков вокруг зоны видимости,
`FULL_RADIUS=4`) при выгрузке клались в io_write безусловно
(`schedule.rs`, ветка `Chunk::Proto`), `upgrade_to_level_chunk` ставил
`dirty=true` безусловно, а дефолтный Anvil (`write_in_place=false`)
переписывал весь `.mca` целиком — с полным перечитыванием региона после
эвикции кэша сериализатора.

## Сценарий замера

Интеграционный тест `pumpkin-world/tests/dirty_hygiene.rs`
(`revisit_without_modification_writes_nothing`): flat-мир, тикет уровня 46
(Features) на чанк (0,0) → генерация и сохранение → два повторных открытия
уровня той же области без модификаций (второе — с явным прогоном
process_unload_queue). Замер — по регион-файлам (размер + mtime + хэш
содержимого).

## Результат: записанные байты на «повторный визит»

| | регион-файлов переписано | байт записано |
|---|---|---|
| До (master + фикс flat-стадий) | 4 (`r.0.0`, `r.0.-1`, `r.-1.0`, `r.-1.-1`) | **135 168** |
| После | **0** | **0** |

Каждый визит до фикса дополнительно **перечитывал** те же 4 файла целиком
(read-modify-write в `ChunkFileManager::get_serializer`) — то есть на HDD
сценарий «пробежка по старой территории» стоил ~270 КБ I/O на игрока на
каждую границу выгрузки, при нулевой новой информации.

Контр-тест (`revisit_with_stage_advancement_writes`): продвижение стадии
(тикет 47 → 46) по-прежнему приводит к записи. Шатдаун сохраняет
модифицированные прото; немодифицированные пропускаются.

## Бенчмарк (горячий путь генерации)

`cargo bench -p pumpkin-world --bench chunk_gen -- full_chunk_generation`,
baseline `main` снят на том же коммите master (стэш):

| | время |
|---|---|
| master (baseline `main`) | 31.112 мс |
| после изменений | 31.043 мс (−0.22%, в пределах шума) |

## Попутные находки

1. **Livelock flat-миров (исправлен, коммит `6fcc5697`):** ветки Flat для
   `StructureStart`/`StructureReferences` в `Cache::advance` не выставляли
   стадию — flat-чанк навсегда застревал на Biomes, планировщик бесконечно
   перезапускал задачу (~450% CPU), тикет уровня 43 (Full) никогда не
   завершался. Ванильная (noise) генерация не затронута.
2. **Потеря dirty при ошибке записи (исправлена, коммит `3c9de41e`):**
   `save_chunks` сбрасывал dirty до записи и не восстанавливал при ошибке —
   изменения молча терялись до следующей мутации чанка.
3. **Шатдаун-гонка (НЕ исправлена, кандидат в отдельный PR):** чанки,
   прилетающие от ген-потоков после `save_all_chunk(true)` в цикле
   завершения планировщика, принимаются, но уже не сохраняются
   (`schedule.rs`, дренаж после `break`). В тестах компенсируется
   warm-up-фазой.
4. Clippy на воркспейсе падает из-за отсутствующей директории
   `pumpkin-plugin-wit/v0.1` (состояние чекаута, не связано с PR);
   `cargo clippy -p pumpkin-world -- -D warnings` — чистый.
